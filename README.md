# Портал для учителей — создание учебно-методических материалов

Минималистичный веб-сервис на **Python / Django**, который помогает учителям быстро создавать учебно-методические материалы для школы с помощью связки «шаблон + данные пользователя + AI».

> Основной сценарий: **Класс → Предмет → Тип материала → Параметры → Генерация → Редактирование → Экспорт**

Сервис не перегружен публикациями, курсами, рекламой и рейтингами. Главная задача — экономить время преподавателя на подготовке документов.

## Роли пользователей

**Учитель**
- регистрация и авторизация;
- выбор класса, предмета и типа материала;
- заполнение параметров;
- создание материала (генерация через AI);
- редактирование результата;
- сохранение материалов;
- скачивание DOCX / PDF / PPTX (по мере готовности);
- просмотр ранее созданных материалов.

**Администратор** (Django Admin)
- управление пользователями;
- добавление и редактирование классов и предметов;
- создание типов материалов;
- редактирование AI-шаблонов и промптов без изменения кода;
- управление библиотекой материалов;
- просмотр базовой статистики использования.

## Типы генерируемых материалов

| Тип | MVP | Примечание |
|---|---|---|
| Поурочный план | 1 | цель, задачи, результаты, этапы урока, практическое задание, рефлексия, домашнее задание |
| Тест | 1 | 5/10/15/20 вопросов, сложность, форматы ответов |
| Рабочий лист | 1 | теория, примеры, задания разной сложности, место для ответа |
| Презентация | 1 | 5/7/10/15 слайдов, стиль (минималистичный / яркий / академический). Экспорт PPTX — MVP 2 |
| КТП | 2 | импорт тем из DOCX/XLSX/текста |
| Рабочая программа | 2 | титульный лист, пояснительная записка, тематическое планирование и т.д. |
| Контрольная / самостоятельная работа и др. | 2+ | расширяемые типы через админку |

## Архитектура

```
Frontend (Django templates + Tailwind)
        │
        ▼
   Django (Views + DRF API)
        │
   ┌────┼─────────────┐
   ▼    ▼             ▼
SQLite   AI API    Generator Service
  │      (LLM)        ├── DOCX (python-docx)
  │                   ├── PPTX (python-pptx, MVP 2)
  │                   ├── XLSX (openpyxl, MVP 2)
  │                   └── PDF  (WeasyPrint)
  ▼
Файлы → S3 / MinIO (production)
```

- **Generator Service** — оркестратор: принимает параметры пользователя, рендерит промпт из шаблона, вызывает AI, преобразует ответ в структурированный документ.
- **AI API** — абстракция над любым OpenAI-совместимым LLM (локальный Ollama, OpenRouter и т.п.).

## API

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/api/grades/` | получить классы |
| GET | `/api/subjects/` | получить предметы |

| POST | `/api/materials/generate/` | создать материал |
| GET | `/api/materials/{id}/` | получить материал |
| PATCH | `/api/materials/{id}/` | изменить материал |
| POST | `/api/materials/{id}/export/` | экспортировать материал |

Пример запроса на генерацию:

```json
{
  "grade": 7,
  "subject": "history",
  "type": "lesson_plan",
  "topic": "Древняя Греция",
  "duration": 45
}
```

## Основной пользовательский сценарий

1. Пользователь выбирает **класс** (кнопки 1–11).
2. Выбирает **предмет** (список управляется админом).
3. Выбирает **тип материала** (поурочный план, тест и т.д.).
4. Заполняет **параметры**: тема урока, продолжительность, тип урока, дополнительные блоки и т.п.
5. Нажимает **«Создать материал»** → запускается генерация.
6. Результат открывается в **редакторе** — текст можно менять до экспорта:
   - заголовки и абзацы;
   - жирное начертание;
   - маркированные и нумерованные списки;
   - таблицы;
   - изображения;
   - добавление и удаление блоков.
7. Действия: **Изменить / Сгенерировать заново / Сохранить / Скачать DOCX / Скачать PDF**.
8. Материалы попадают в личный кабинет «Мои материалы» с фильтрами (иконки: Открыть / Копировать / Скачать / Удалить).

Пример таблицы поурочного плана:

| Этап | Время | Действия учителя | Действия учащихся |
|---|---|---|---|
| Организационный этап | 2 мин | ... | ... |
| Актуализация знаний | 5 мин | ... | ... |
| Изучение темы | 20 мин | ... | ... |
| Закрепление | 10 мин | ... | ... |
| Рефлексия | 5 мин | ... | ... |

## AI-генерация

Используется связка **«шаблон + данные пользователя + AI»**, а не свободная генерация.

Промпты хранятся в базе (админка) и содержат переменные:

```
{{grade}} {{subject}} {{topic}} {{duration}}
```

Пример промпта:

```
SYSTEM: Ты образовательный методист. Не изменяй класс и дисциплину.
USER: Класс: 7\nПредмет: История\nТема: Древняя Греция\nДлительность: 45 минут\n
      Составь поурочный план.\nСтруктура:\n1. Цель\n2. Задачи\n3. Планируемые результаты
      \n4. Этапы урока\n5. Практическое задание\n6. Рефлексия\n7. Домашнее задание
```

**AI-команды внутри редактора**
- сократить;
- расширить;
- сделать понятнее;
- адаптировать для другого класса;
- добавить пример;
- добавить практическое задание;
- добавить вопросы;
- проверить ошибки.

### Подключение модели

AI-клиент реализован поверх **OpenAI-совместимого API** (`/v1/chat/completions`). Это позволяет подключать любой провайдер через переменные окружения:

- **Ollama (локально, бесплатно, по умолчанию):** `AI_BASE_URL=http://localhost:11434/v1`, запустите модель, например `ollama run qwen3:27b` (модель задаётся в `AI_MODEL`).
- **OpenRouter и другие бесплатные API:** укажите `AI_BASE_URL`, `AI_MODEL` и `AI_API_KEY`.

Если LLM недоступен, срабатывает **fallback-генератор**: материал формируется из встроенных шаблонов, чтобы основной сценарий всегда работал (используется также в тестах).

## Быстрый старт

Требования: Python 3.13+.

```bash
# 1. Клонировать/перейти в папку проекта, создать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Скопировать .env.example в .env и при необходимости поправить
copy .env.example .env

# 4. Применить миграции и загрузить начальные данные
python manage.py migrate
python manage.py loaddata apps/subjects/fixtures/initial.json

# 5. Создать администратора
python manage.py createsuperuser

# 6. Запустить сервер
python manage.py runserver
```

Открыть http://127.0.0.1:8000/. Админка — http://127.0.0.1:8000/admin/.

### PDF

PDF формируется через **WeasyPrint** (используется там, где установлены GTK-библиотеки — Linux, серверы). На Windows автоматически включается **fallback на ReportLab** с регистрацией системного TTF-шрифта (Times New Roman / Arial), поэтому кириллица в PDF отображается корректно без дополнительных установок.

### Настройка AI (необязательно)

```bash
# установить Ollama: https://ollama.com
ollama pull qwen3:27b
ollama run qwen3:27b   # проверить работу
# сервер Ollama отвечает на http://localhost:11434 — этого достаточно,
# клиент портала будет обращаться к http://localhost:11434/v1
```

Без подключённого AI портал работает на fallback-шаблонах.

## Этапы разработки

**MVP 1** (в процессе)
- авторизация;
- выбор класса / предмета / типа материала;
- генерация поурочного плана, теста, рабочего листа, презентации;
- редактор результата (TipTap) + AI-команды;
- сохранение и повторное открытие материалов;
- экспорт DOCX / PDF;
- админка: предметы, классы, типы материалов, AI-шаблоны, пользователи;
- каркас под библиотеку, КТП, рабочие программы, «Предмет учителя».

**MVP 2**
- КТП (импорт из DOCX/XLSX/текста);
- рабочие программы;
- экспорт PPTX;
- библиотека и публикация материалов;
- поиск.

**MVP 3**
- загрузка рабочих программ;
- анализ структуры программы;
- автоматическое формирование тем курса;
- генерация материалов по конкретным темам программы.

**Развитие продукта**
Переход к логике **«Предмет учителя»**: учитель создаёт курс («История — 7 класс»), загружает рабочую программу, сервис строит структуру разделов и уроков. Для каждого урока доступны действия: Объяснение / Презентация / Тест / Рабочий лист — сервис превращается в рабочее пространство учителя на учебный год.

## Критерии приёмки MVP

- пользователь может зарегистрироваться и войти в систему;
- можно выбрать класс, предмет и тип материала;
- материал создаётся на основе введённых параметров;
- результат можно редактировать;
- материал сохраняется в личном кабинете;
- материал можно повторно открыть;
- DOCX и PDF формируются без потери структуры;
- ошибки генерации корректно обрабатываются и показываются пользователю;
- администратор может изменять предметы, типы материалов и AI-шаблоны без изменения кода.
