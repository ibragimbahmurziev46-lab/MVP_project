# Project Notes — Образовательная платформа

## 🎯 Идея проекта

Платформа для онлайн-обучения, где преподаватели публикуют курсы,
а студенты их проходят, сдают тесты и получают сертификаты.
Аналог-ориентир: Infourok, Stepik, Skillbox.

---

## 🧩 MVP (что делаем в первую очередь)

- [ ] Регистрация / авторизация (студент, преподаватель)
- [ ] Каталог курсов с поиском и фильтрами
- [ ] Карточка курса: описание, программа, автор
- [ ] Запись на курс
- [ ] Прохождение уроков (текст + видео)
- [ ] Простой тест после урока
- [ ] Личный кабинет: мои курсы, прогресс

##  Технический стек (черновик)

- **Backend:** Python + FastAPI / Django
- **Frontend:** React / Vue
- **БД:** PostgreSQL
- **Кэш:** Redis
- **Файлы:** S3 / MinIO
- **Очереди:** Celery + RabbitMQ
- **Деплой:** Docker + Docker Compose
- **CI/CD:** GitHub Actions
